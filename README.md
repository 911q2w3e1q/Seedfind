# Minecraft 种子查询器（Java 版）

一个面向 Java 版 Minecraft 的本地工具，支持**全版本种子/生物群系/结构查询**、**框选区域与方块/矿石搜索**、**结构 + Y 坐标筛选**、**一键 3D 预览**，以及**读取本地存档（仅已加载区块）**。

底层使用 [Cubiomes](https://github.com/Cubitect/cubiomes)（经 `cubiomespi-fork` Python 绑定）做精确的种子级世界生成计算，使用 `anvil-parser2` 读取存档 `.mca`。

---

## 功能对照（对应你的需求）

| 需求 | 实现 |
| --- | --- |
| 查询所有 Java 版本种子号 | 版本下拉框覆盖 **MC 1.0 ~ 1.21**（24 个里程碑版本）+ **日历版号 26.1 / 26.2 / 26.3**（1.21.11 之后；与 1.21.4 同生成算法，坐标真实有效），任意 64 位整数种子 |
| 正常的结构查询 | 村庄、神庙、府邸、神殿、要塞、前哨站、末地城、远古城市、堡垒、下界要塞等 |
| **查看当前结构的 3D 形状** | 搜到结构后点“**查看结构 3D 形状**”，在弹窗里用近似真实尺寸的 3D 模型展示该结构的大小、比例与外形（见下方说明） |
| 框选区域 / 区块查询有哪些方块 | 地图上**左键拖拽框选**区域；种子模式给出该区域矿石构成，存档模式给出真实方块统计 |
| 搜索方块（如钻石） | 方块下拉框选“钻石/绿宝石/金/铁/煤/青金石/红石/铜/远古残骸…”，列出坐标与 Y |
| 搜索结构 + 选 Y 坐标找合适的 | 选结构（如**女巫小屋**）→ 设 **Y 范围**与**距出生点上限** → 按半径或选区筛选 |
| 一键切换 3D 预览 | “一键 3D 预览”按钮，在同一面板内切换 2D/3D（可拖拽旋转、滚轮缩放） |
| 查询存档（仅已加载） | 打开存档文件夹，只渲染/搜索磁盘上**实际存在**的区块，不凭空生成新区块 |
| **安卓版** | 见 [`android/README_android.md`](android/README_android.md)，提供可编译的 Kivy 工程与一键出包教程 |

## 运行方式

### 方式一：直接运行（无需打包）
1. 安装 Python 3.10+（Windows 勾选 “Add to PATH”，默认已含 tkinter）。
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 启动：
   ```bash
   python main.py
   ```

### 方式二：打包成 Windows exe（推荐分发）
双击运行根目录下的 **`build_windows.bat`** 即可一键生成 `dist\MinecraftSeedQuery\MinecraftSeedQuery.exe`。

> `cubiomes` 包含原生 C 扩展，首次安装会调用 **Microsoft C++ 生成工具**自动编译；若报错提示缺少编译器，请到 Visual Studio Installer 勾选“使用 C++ 的桌面开发”工作负载后重跑脚本。

## 使用说明

### 种子查询（第一个标签页）
1. 输入**种子**（留空或点“随机”可生成随机种子），选择**版本**与**维度**。
2. 点 **生成 / 刷新地图**，会在画布上渲染生物群系彩色地图（自动居中到出生点）。
3. 地图操作：
   - **左键拖拽** = 框选区域；**右键拖拽** = 平移；**滚轮** = 缩放；也可点“放大/缩小/回出生点/清除选择”。
   - 选区信息会实时显示在下方；不选则默认使用整张地图范围。
4. **结构查询**：选结构 → 填 Y 范围（可选）/ 距出生点上限 → “搜索选区内结构”或“按半径搜附近”。
   - 例：搜“女巫小屋”，设 Y 在 `[55, 70]`、距出生点 `< 5000`，即可筛出“合适”的女巫小屋。
5. **方块/矿石查询**：选方块 → “搜索该方块坐标”列出坐标（Y 精确）；“区域方块构成”给出该区域各矿石的预计矿脉数。
6. **查看结构 3D 形状**：先搜到结构（或选中结果行）→ 点“查看结构 3D 形状”，弹窗会用近似真实尺寸的 3D 模型画出该结构的外形（大小/比例直观可见，可拖拽旋转缩放）。
7. **一键 3D 预览**：切换到 3D，展示当前视图的地形高度（种子模式为生物群系估算；存档模式为真实高度）与结构/方块散点。

### 存档查询（第二个标签页）
1. 点 **打开存档文件夹**，选择含 `level.dat` 的存档根目录（会自动读取种子、版本、可用维度）。
2. 选维度 → 点 **加载地图（仅已加载区块）**：灰色=未加载，彩色=已加载区块的真实顶部方块。
3. 框选区域后：
   - **搜索方块**（如 `diamond_ore` / `chest` / `spawner`）：在已加载区块里精确检索并给出坐标。
   - **选区方块构成**：统计该区域真实方块出现次数。
4. **一键 3D 预览**：展示已加载区块的真实地形与找到的方块。

## 重要说明（避免误解）

- **种子模式的矿石/方块**是基于官方矿石生成参数（Y 区间、矿脉大小、密度）做的**概率分布级模拟**：**Y 区间精确、坐标近似**（由确定性随机数复现）。它用来告诉你“钻石大约在哪一层、密度多大”，而不是逐方块还原世界。
- **存档模式的方块/地图**是**真实数据**：直接读取 `.mca` 里实际生成的方块，只覆盖玩家曾经加载过的区块（符合你“只能查看已经加载的”的要求）。
- **矿井（Mineshaft）**按区块随机生成、无单一锚点，故不提供精确定位；其余结构均可定位。
- 结构 Y 坐标：部分结构（如女巫小屋、村庄）随地形起伏，工具给出**估算地表 Y**用于筛选；远古城市、海底神殿等使用其特征 Y。

## 文件结构

```
main.py        图形界面与全部交互逻辑（tkinter，桌面版）
engine.py      Cubiomes 封装：版本/结构/生物群系地图/结构定位/高度估算
ores.py        矿石分布模型（官方参数 + 确定性 PRNG，给出近似坐标）
saves.py       存档读取（anvil-parser2）：仅已加载区块、真实方块查询
mapview.py     地图画布（框选/平移/缩放 + matplotlib 3D 预览，桌面版）
structures_3d.py  各结构的近似 3D 外形模型 + matplotlib 绘制（桌面/安卓共用）
requirements.txt   依赖
build_windows.bat  一键打包为 Windows exe
android/        Kivy 安卓工程（main.py + buildozer.spec + cubiomespi 本地包 + recipe + README_android.md）
```

## 版本说明（已联网核实）
- **版本覆盖**：MC 1.0 ~ 1.21（共 24 个里程碑版本），以及 Mojang 2025-12 起启用的**日历版号 26.1 / 26.2 / 26.3**（1.21.11 之后依次为 26.1→26.2→26.3）。
- **26.x 是真版本，不是假的**：经多源核实（minecraft-guides / mcseedview / 1337wiki 的 cubiomes 种子地图），26.x 的世界生成算法与 **1.21.4 完全一致**，村庄/神庙/生物群系位置不变。因此本应用把 26.x 直接映射到 Cubiomes 的 `MC_1_21` 生成器，产出的生物群系与结构坐标对 26.x 是**真实有效的**。
- 底层 Cubiomes 库目前枚举最高到 `MC_1_21`；由于 26.x 与之同算法，无需单独实现即可正确服务 26.x。若未来 Mojang 真正改动世界生成（如 27.x 换新算法），需等 Cubiomes 更新枚举后再接入。

## 已知限制
- **结构 3D 形状**是基于真实结构尺寸的**示意模型**（包围盒 + 风格化实体），用于直观查看结构的大小、比例与大致外形；它不是逐方块还原（逐方块真实数据请用“存档查询”读取实际世界）。
- 种子模式不对“逐方块”做完全还原（见上）；若要逐方块真实数据，请用“存档查询”。
- 3D 地形在种子模式为生物群系类别估算，仅作形态参考。
- **存档读取**：26.1 起 Minecraft 改了存档目录结构（各维度移入 `dimensions/minecraft/<dim>/region`），本应用已兼容新旧两种布局；但 `.mca` 仍是未压缩/压缩的区段文件，anvil-parser2 读取逻辑不变。

## 安卓版

提供用 **Kivy** 重写的安卓工程，复用同一套 `engine/ores/saves/structures_3d` 引擎逻辑，功能与桌面版一致（种子/结构/矿石/存档 + 2D 地图框选 + 3D 预览 + 结构 3D 形状）。

- 工程与编译教程见：[`android/README_android.md`](android/README_android.md)
- 直接交付的是**可编译工程 + 一键出包教程**（不是预编译 APK），因为 `cubiomes` 原生库需要在你自己的电脑上用 Android NDK 交叉编译成手机架构，沙箱里直接编 APK 容易失败。按教程在自己电脑上即可产出可安装的 `.apk`。
